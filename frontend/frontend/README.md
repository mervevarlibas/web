# Kampüs Etkinlikleri - Frontend Projesi

Bu proje, üniversite kampüsündeki seminer, atölye ve söyleşileri tek yerden takip etmeyi sağlayan bir React ve TypeScript web uygulamasıdır.

## Canlı Bağlantı (Vercel)
Projenin Vercel üzerindeki canlı sürümüne aşağıdaki bağlantıdan ulaşabilirsiniz:
[https://mervevarlibas-frontend.vercel.app](https://mervevarlibas-frontend.vercel.app)

## Kullanılan Teknolojiler
- React & TypeScript
- React Router (Sayfa yönlendirmeleri)
- Context API (Global state yönetimi)
